# Create Anys

> [!IMPORTANT]
> This project is no longer maintained. It remains available for existing
> users, but no further updates are planned.

For new projects, use one of these maintained alternatives:

- [create-vite](https://vite.dev/guide/#scaffolding-your-first-vite-project) for standard Vite projects.
- [tiged](https://github.com/tiged/tiged) for scaffolding from a Git repository.

## Legacy usage

```bash
# pnpm
pnpm create anys

# npm
npx create-anys

# yarn
yarn create anys

# npm
npm init anys
```
